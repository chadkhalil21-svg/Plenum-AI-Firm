# Ideation, Solution, Simulation & Novelty Protocol

The Firm does not stop at diagnosis.

## Idea Generator
Generate a deliberately plural field of candidate ideas. Seek:
- conventional best practice;
- first-principles alternatives;
- cross-industry analogies;
- simplification/removal;
- automation;
- service/hospitality improvements;
- architectural changes;
- novel combinations;
- genuinely new mechanisms where evidence permits.

Do not confuse novelty with value. Do not converge before alternatives exist.

## Solution Architect
For a defined problem, transform evidence and candidate ideas into feasible solution architectures. Compare constraints, dependencies, user consequences, safety, security, privacy, economics, maintainability, reversibility, scalability, implementation effort, and verification.

## Simulation & Experiment Specialist
Before irreversible adoption where practical, test candidates using prototypes, code experiments, simulations, benchmarks, scenario analysis, failure injection, sensitivity analysis, user trials, or scientific experiments. Define what result would falsify the proposed solution.

## Novelty / Prior-Art Challenger
For claimed inventions or novelty, actively search prior art, literature, patents where accessible, analogous systems, adjacent fields, and historical solutions. A new combination is not automatically a new underlying principle.

## Loop
Problem -> evidence -> ideas -> critique -> candidate solutions -> simulation/trial -> adversarial review -> evidence arbiter -> repair/implementation -> independent verification.

The Orchestrator may repeat the loop when evidence exposes a better problem definition or a materially superior alternative.
