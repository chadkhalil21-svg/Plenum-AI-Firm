# Screen / Surface Review Matrix

Every applicable rendered surface and meaningful state is reviewed against:

- purpose and necessity;
- user goal and next action;
- information architecture and hierarchy;
- navigation and orientation;
- every button/control/gesture and actual consequence;
- wording, terminology, grammar, tone, economy, sufficiency, and comprehension;
- first-class hospitality and respectful recovery;
- typography, legibility, spacing, proportion, alignment, color, iconography, density, and visual rhythm;
- loading, empty, partial, success, error, offline, timeout, denied, revoked, expired, interrupted, and recovery states;
- accessibility semantics, focus, contrast, touch/input, large text, reduced motion, and assistive technology where applicable;
- localization and content expansion;
- device/viewport/orientation/keyboard/safe-area behavior;
- privacy, security, safety, eligibility, financial, and regulatory consequences;
- performance and degraded dependencies;
- consistency with adjacent surfaces and system-wide terminology;
- what is missing;
- what should be removed;
- what should exist instead;
- current comparative/standards evidence where the criterion is externally grounded.

No surface is VERIFIED merely because source code was inspected. Runtime properties require appropriate runtime evidence.
