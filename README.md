# Plenum AI Firm

Plenum AI Firm is an independent AI engineering institution for architecture, implementation, verification, adversarial review, and evidence-bound software delivery.

## Institutional premise

The Firm does not treat model confidence as evidence. Engineering claims are bound to an immutable candidate revision and are evaluated by independently tasked workers, deterministic checks, adversarial review, supervisory orchestration, and an evidence authority.

The Firm is project-independent. Client systems remain separate repositories. American Rider is Project 001 and the first commissioning assignment.

## Authority model

1. **Primary Orchestrator** decomposes a mandate into falsifiable claims and dispatches work.
2. **Ground-Truth Division** reconstructs the client system before judgment.
3. **Specialist Divisions** inspect architecture, product, security, reliability, design, language, accessibility, economics, and domain requirements.
4. **Adversarial Division** searches for omissions, contradictions, bypasses, stale assumptions, broken journeys, and regressions.
5. **Supervisory Orchestrator** audits the Primary Orchestrator itself for omitted work, biased routing, incomplete coverage, and premature closure.
6. **Deterministic Watchdog** enforces mechanical invariants that no model may waive.
7. **Evidence Arbiter** adjudicates claims from evidence and cannot implement repairs.
8. **Repair Division** changes client code only after an adjudicated finding or authorized engineering mandate.
9. **Independent Verification** re-tests repairs against the resulting immutable revision.

## Non-negotiable rules

- Exact revision before conclusion.
- Current implementation before historical claim.
- Absence must be proved, not assumed.
- Implementers do not certify their own work.
- A passing test proves only what it actually exercised.
- Unknown, inaccessible, or unexecuted work is **NOT TESTED**, never silently passed.
- Candidate revision changes invalidate evidence unless invariance is explicitly established.
- The Primary Orchestrator cannot certify itself.
- The Supervisory Orchestrator cannot silently rewrite the Primary Orchestrator's record.
- The Evidence Arbiter cannot repair code.
- Deterministic gates cannot be overridden by model confidence.
- Client repositories remain separate from the Firm.

## Commissioning

Project 001: **American Rider**.
